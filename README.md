This repository contains all 10 experiments performed during my 4th semester laboratory course on Real Time Operating Systems (RTOS). The experiments were implemented using STM32 Nucleo-F446RE and FreeRTOS, covering important RTOS concepts such as task management, scheduling, semaphores, queues, synchronization, and inter-task communication. The repository serves as a complete collection of practical RTOS implementations and learning outcomes from the semester.
